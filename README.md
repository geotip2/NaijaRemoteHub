# 🇳🇬 NaijaRemoteHub

**Work Remotely. Earn in Naira.**

NaijaRemoteHub is a platform for Nigerians to find remote jobs, learn skills, and earn money with referrals — no experience needed to start.

🌐 **Live Website:** https://geotip2.github.io/NaijaRemoteHub/

---

## ✨ Features

- **Create Free Account** - Signup with Name, Phone, Email & Password
- **Login & Dashboard** - Personal dashboard for every user
- **Wallet System** - See your earnings in Naira (₦)
- **Referral System** - Earn ₦500 per person you invite
- **Referral Levels** - L1 / L2 / L3 earnings
- **Copy Referral Link** - One-click share to WhatsApp, Facebook, X
- **Featured Remote Jobs** - Virtual Assistant, Social Media, Data Entry, Customer Support
- **Training Section** - Learn how to start earning
- **Admin Login** - Manage the platform

## 💰 How To Earn

1. **Create Account** - It's free
2. **Copy Your Referral Link** - From your Dashboard
3. **Share It** - Send to friends on WhatsApp, Status, Facebook, TikTok
4. **Earn ₦500** - For every person who registers with your code
5. **Apply For Jobs** - Earn ₦40k - ₦180k / month from remote jobs
